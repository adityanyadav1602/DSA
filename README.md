# Data Structures and Algorithms (DSA)

Implementations and solutions in Python covering fundamental data structures, algorithms, and object-oriented programming concepts.

## Structure
- **Linked Lists**: Implementation of Singly & Doubly Linked Lists, insertion, deletion, and reversal
- **Algorithms & LeetCode Practice**: 3Sum, Add Two Numbers, Longest Substring, Median of Two Sorted Arrays, etc.
- **OOP Concepts**: Classes, dunder methods (`__new__`), duck typing
